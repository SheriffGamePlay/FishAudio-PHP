# Fish Voice Studio

Веб-сайт на чистом PHP (без фреймворков и Composer) для работы с [Fish Audio API](https://docs.fish.audio):
озвучка текста, клонирование голоса с сохранением, библиотека голосов, распознавание речи, дизайн голоса.

## Возможности

| Раздел | Что делает | Эндпоинт Fish Audio |
|---|---|---|
| Озвучка | Текст → речь. Модель, формат (mp3/wav/opus), скорость, громкость, выразительность, top-p, режим задержки, нормализация текста. **Диалог** из нескольких голосов (теги `<\|speaker:N\|>`) | `POST /v1/tts` |
| Клонирование | Загрузка 1–10 образцов (+ необязательные транскрипты), улучшение записи, выбор доступа. Голос **запоминается** в вашем списке | `POST /model` |
| Мои голоса | Список сохранённых голосов, переименование, смена доступа (приватный / по ссылке / публичный), удаление, добавление по ID, импорт голосов из аккаунта Fish | `GET/PATCH/DELETE /model/{id}` |
| Библиотека | Поиск чужих голосов (название, язык, сортировка), прослушивание, сохранение к себе | `GET /model` |
| Распознавание | Аудио/видео → текст, таймкоды и разбивка по спикерам | `POST /v1/asr` (`transcribe-1-pro`) |
| Дизайн голоса | Описание голоса словами → 1–4 варианта, лучший сохраняется как голос | `POST /v1/voice-design` |
| История | Все озвучки хранятся на сервере: прослушать, скачать, удалить, вернуть текст в редактор | — |
| Аккаунт | Баланс кредитов и пакета | `GET /wallet/self/api-credit`, `/package` |

Свои голоса, история и файлы изолированы между пользователями сайта; ключ Fish Audio один (серверный) и в браузер не попадает.

## Требования

- PHP **8.1+** с расширениями `curl`, `pdo_sqlite`, `mbstring`, `json`
- Веб-сервер с корнем в каталоге `public/` (или `php -S` для локального запуска)
- API-ключ: <https://fish.audio/app/api-keys/>

## Установка

```bash
cp .env.example .env        # впишите FISH_API_KEY
php -S 127.0.0.1:8080 -t public
```

Откройте <http://127.0.0.1:8080>: на пустой базе сайт предложит создать первую учётную запись.
Дополнительных пользователей можно создать из консоли:

```bash
php bin/create-user.php логин [пароль]     # без пароля — сгенерирует
```

Каталог `storage/` (база SQLite, сессии, аудио) создаётся автоматически и должен быть **доступен PHP на запись** и **недоступен из интернета**.

### Продакшен

**Корень сайта — `public/`.** `.env`, `src/`, `storage/` не должны быть доступны по HTTP.

Nginx (пример):

```nginx
server {
    root /var/www/fish-tts-web/public;
    index index.php;
    client_max_body_size 64m;                 # ≥ MAX_UPLOAD_MB * 10 для клонирования
    location / { try_files $uri $uri/ =404; }
    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_read_timeout 960s;            # распознавание длинных записей идёт минутами
    }
    location ~ /\. { deny all; }
}
```

В `php.ini` проверьте `upload_max_filesize` и `post_max_size`: по умолчанию они часто 2M/8M, чего мало для аудио.
Нужно не меньше `MAX_UPLOAD_MB` на файл и `MAX_UPLOAD_MB × число файлов` на запрос. Сайт покажет понятную ошибку, если лимит превышен.
Включите HTTPS: тогда cookie сессии получит флаг `Secure`.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `FISH_API_KEY` | — | ключ Fish Audio (обязательно) |
| `TTS_MODELS` | `s2.1-pro-free` | модели, доступные в интерфейсе (первая — по умолчанию) |
| `REGISTRATION` | `closed` | `open` — любой может зарегистрироваться |
| `MAX_TTS_CHARS` | `5000` | максимум символов за один запрос |
| `DAILY_CHAR_LIMIT` | `0` | лимит символов на пользователя за 24 часа (0 — нет) |
| `MAX_UPLOAD_MB` | `20` | максимальный размер одного файла |
| `FISH_PROXY` | — | прокси для запросов к Fish |
| `FISH_BASE_URL` | `https://api.fish.audio` | менять только в тестах |

## Безопасность

- Весь доступ к Fish идёт через ваш общий ключ — не открывайте регистрацию без `DAILY_CHAR_LIMIT`, иначе посторонние смогут тратить ваш лимит/кредиты.
- Пароли хранятся как bcrypt/argon (`password_hash`), вход ограничен 8 неудачными попытками с одного IP за 15 минут, сессия пересоздаётся при входе.
- Все POST-запросы защищены CSRF-токеном; доступ к аудио проверяется по владельцу; пути файлов строго внутри `storage/`.
- Если сайт стоит за обратным прокси, ограничение попыток считается по `REMOTE_ADDR` — настройте передачу реального IP на уровне веб-сервера (`mod_remoteip`, `real_ip_header`).
- Платные модели (`s2.1-pro`, `s2-pro`) тратят кредиты вашего аккаунта — добавляйте их в `TTS_MODELS` осознанно.

## Про бесплатную модель `s2.1-pro-free`

По данным блога Fish Audio: безлимит в рамках Fair Use, **без SLA**, запросы могут использоваться для улучшения модели,
для продуктов с выручкой выше $1M ARR нужно согласование, бесплатный период заявлен **до 30 ноября 2026** — после этой даты
проверьте условия и, при необходимости, добавьте платную модель в `TTS_MODELS`.

## Тесты

```bash
tests/run.sh
```

Копирует проект во временный каталог, поднимает мок Fish API (`tests/mock_fish.php`) и прогоняет сквозной сценарий `tests/e2e.php`
(регистрация, CSRF, клонирование, синтез, диалог, библиотека, STT, дизайн, история, изоляция пользователей) — около 60 проверок.
Ваши `storage/` и `.env` не затрагиваются.

> **Важно:** мок написан по документации Fish Audio, а не по реальному сервису. Тесты проверяют, что сайт отправляет в API то,
> что описано в документации, но живых запросов к настоящему Fish Audio при разработке не выполнялось.
> При первом запуске с настоящим ключом пройдите сценарий вручную: создайте клон → озвучьте им текст → распознайте результат.

## Что не реализовано

- Мгновенное клонирование «на лету» через `references` (нужен MessagePack; вместо него используется постоянный клон — он и сохраняется).
- Потоковый WebSocket-синтез, словари произношения, голосовые агенты (`/v1/agent/*`) и их телефония.
- Профессиональное клонирование (PVC) — по документации доступно только в веб-приложении Fish.
